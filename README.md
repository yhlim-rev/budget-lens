# Budget Lens — Expense & AI Analytics Dashboard

Privacy-first, dual-currency ($ USD & ៛ KHR) envelope budgeting ledger built with **React 18**, **Tailwind CSS**, and **Recharts**.

## 🚀 Quickstart

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## 📦 Architecture & Stack
- **Frontend Framework**: React 18 + Vite
- **Styling**: Tailwind CSS (Dark theme with `#e8834a` brand orange)
- **Data Visualizations**: Recharts (`PieChart` rounded donut & `AreaChart` cash outflow curve)
- **Currency Engine**: 1 USD = 4,050 KHR exchange peg with dual logging
- **Zero-Login / Local-First**: 100% private in-browser storage
